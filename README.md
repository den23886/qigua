# 起个卦 · qigua.work

一个自己动手做的传统文化小工具，把三种方法放在同一个网页里：

- **周易起卦** —— 六十四卦，支持时间起卦与手动起卦
- **塔罗占卜** —— 22 张大阿卡纳，单张 / 三张 / 凯尔特十字
- **奇门遁甲** —— 时家转盘排盘，支持真太阳时经度校正

在线使用：<https://qigua.work>

不做「命中注定」的宣判，只把卦象和牌面摆出来，帮你把当下的事情想清楚一点。

## 技术说明

- 前端：单文件 HTML（原生 JS，无框架、无构建）
- 后端：Cloudflare Pages Functions（`functions/api/*`），KV 存储账号与订单
- AI 解读：服务端代理调用大模型，密钥不下发到前端
